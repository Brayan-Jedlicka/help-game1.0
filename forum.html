Colisões precisas: instance_place ou place_meeting?

Toda resposta técnica no fórum Help Game vem acompanhada de uma explicação — nunca apenas o código.

Tópico · Movimentação e Colisões

JV
joaovitor_dev membro
Estou a testar colisões de máscara com o meu obj_player contra obj_inimigo, mas às vezes a personagem atravessa antes do dano ser aplicado. Uso instance_place(x, y, obj_inimigo). Alguma ideia?
HG
Help Game moderador
Para esse caso, troque para place_meeting(x, y, obj_inimigo) — ele só verifica se há colisão na posição indicada, sem precisar de devolver o id da instância. Como você só quer saber "houve contacto?", isso evita o custo extra de instance_place, que também procura e devolve a instância encontrada.
Como Funciona: use instance_place quando precisar de agir sobre a instância específica encontrada (ex.: aplicar dano a ela); use place_meeting quando só precisar de um verdadeiro/falso para decidir o próximo passo da lógica — como no tutorial de Dano.
